## Implementation shape (normative intent)

Observed API matches approved intent:

- `CalendarLocalTime`, `CalendarPhrase`, `CalendarMatchConfig`
- `load_calendar_match_config` / compatibility `load_calendar_match_phrases`
- `CalendarMatchCache.get_config()` + `get_phrases()`
- `resolve_calendar_match_options(matched, config)` → first phrase `time`, else `default_time`; first phrase `duration_minutes`, else CLI
- `build_calendar_event_body(..., owner_time=, owner_time_source=)` applies owner clock only when `_schedule_is_date_only`; annotates schedule source / description
- Time parse: `H:MM` / `HH:MM`, hours 0–23, minutes 0–59; no AM/PM/seconds
- Duration: positive whole minutes (`int` or integer-valued `float`); rejects bool/`<=0`/non-integer float
